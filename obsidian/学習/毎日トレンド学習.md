# 毎日トレンド学習

## 学習対象
YouTube Shorts / TikTok の高再生動画から、個別動画の内容をコピーせず「構造」を学習する。

## 毎日記録する項目
- 冒頭0〜2秒のフック
- 何を見せているか
- 結果・結論を先に見せるか
- 動画尺
- カット頻度・テンポ
- 比較 / 検証 / Before-After の有無
- 保存・共有・コメントにつながる理由
- 本編で提示する具体的価値
- CTA
- 節約ジャンルへ転用できる構造

## 現時点の学習パターン
1. すぐ内容が分かる冒頭
2. 「結果を知りたい」状態を作る
3. 比較・検証・数字で具体化
4. 無駄な間を減らす
5. 保存・共有する理由を明示
6. 完璧に作り込みすぎず、実用性・リアリティを残す

## 毎日の成果
- trend-log-YYYY-MM-DD.md を追加
- 素材候補を 動画素材庫/素材台帳.md に追加
- 学習コンテキストへ「採用」「改善」「保留」を記録
