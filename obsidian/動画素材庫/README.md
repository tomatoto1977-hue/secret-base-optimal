# 動画素材庫（秘密基地・最適版）

このフォルダは、ショート動画制作で再利用するフリー素材の候補・ライセンス確認・取得先をObsidianで管理するための保管庫です。

## 基本ルール
- 素材そのものを再配布せず、動画作品の一部として編集して使用する。
- ダウンロード時点のライセンスページを台帳に記録する。
- 人物、ロゴ、商標などが映る素材は個別の権利条件も確認する。
- 自動大量取得・スクレイピングは行わない。

## 主要な取得先
- [Pexels Videos](https://www.pexels.com/videos/)
- [Pixabay](https://pixabay.com/)
- [Mixkit](https://mixkit.co/)

## 毎日の流れ
1. YouTube Shorts / TikTok のトレンド構造を調査
2. 今日使える映像・音・効果音の候補を3〜10件選定
3. ライセンスページを確認
4. 素材台帳へURL・用途・確認日を記録
5. 動画制作時に台帳から候補を選ぶ
6. 投稿後の結果を学習コンテキストへ戻す
